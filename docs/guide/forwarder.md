# 转发器

转发器是 FlowMind 的核心界面，用于实时查看和分析被代理的 HTTP/HTTPS/WebSocket 流量。

## 界面布局


![FlowMind 转发器界面](/screenshots/forwarder-home.png)


## 流量列表

### 列信息

| 列名 | 说明 |
|------|------|
| 方法 | HTTP 方法（GET、POST、PUT 等） |
| URL | 请求的完整 URL |
| 状态码 | HTTP 响应状态码 |
| 大小 | 响应体大小 |
| 耗时 | 请求耗时（毫秒） |
| 时间 | 请求时间戳 |

### 排序与选择

- **排序**：点击列头进行升序/降序排序
- **选择**：点击行选中，支持多选（Ctrl/⌘ + 点击）
- **全选**：Ctrl/⌘ + A

## 过滤功能

### 方法过滤

选择特定 HTTP 方法进行过滤：

- GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS

### 状态码分组

按状态码范围过滤：

| 分组 | 范围 |
|------|------|
| 信息 | 1xx |
| 成功 | 2xx |
| 重定向 | 3xx |
| 客户端错误 | 4xx |
| 服务端错误 | 5xx |

### 搜索过滤

在搜索框输入关键词，会匹配以下字段：

- URL
- 请求头/响应头名称和值
- 请求体/响应体内容

### 域名过滤

按请求域名进行过滤，支持：

- 精确匹配：`api.example.com`
- 通配符匹配：`*.example.com`

## 详情面板

选中流量后，详情面板显示以下标签页：

### 概览

显示请求的基本信息：

- 请求方法和 URL
- 状态码和响应大小
- 请求/响应时间
- 客户端和服务器地址

### 请求

- **请求头**：完整的请求头列表
- **请求体**：请求体内容（支持 JSON、表单、原始格式）

### 响应

- **响应头**：完整的响应头列表
- **响应体**：响应体内容（支持 JSON、HTML、原始格式）

### WebSocket

仅对 WebSocket 流量显示：

- **消息列表**：所有 WebSocket 消息（文本/二进制）
- **关闭帧**：WebSocket 连接关闭信息
- **消息详情**：选中消息的内容预览

### TLS

显示 TLS/SSL 连接信息：

- 协议版本
- 密码套件
- 证书信息
- SNI（Server Name Indication）

### 原始报文

查看请求/响应的原始 HTTP 报文，包括：

- 完整的请求行和请求头
- 原始请求体
- 响应状态行和响应头
- 原始响应体

## 右键菜单

在流量列表中右键点击，可以：

| 操作 | 说明 |
|------|------|
| 发送到重发器 | 将请求发送到重发器进行重放 |
| 发送到模糊器 | 将请求发送到模糊器进行测试 |
| 发送到 AI | 将请求发送给 AI 进行分析 |
| 复制 URL | 复制请求 URL |
| 复制 cURL | 复制为 cURL 命令 |
| 从列表移除 | 从当前列表中移除（不删除数据） |

## 行高亮

支持对流量行进行颜色标记，便于快速识别关注的内容：

1. 右键点击流量行
2. 选择 **设置行高亮**
3. 选择高亮颜色
4. 高亮行在列表中持续显示，重启后保留

## 匹配替换（Match-Replace）

支持自动修改在途请求/响应，无需手动拦截：

| 操作 | 说明 |
|------|------|
| 请求头替换 | 自动修改匹配条件的请求头 |
| 响应头替换 | 自动修改匹配条件的响应头 |
| 请求体替换 | 自动修改匹配条件的请求体 |
| 响应体替换 | 自动修改匹配条件的响应体 |

配置后，代理在转发流量时自动执行替换，适用于：
- 修改测试环境 Host
- 移除安全头（简化测试）
- 注入测试 Cookie 或 Token

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/⌘ + F` | 聚焦搜索框 |
| `Ctrl/⌘ + K` | 清空过滤条件 |
| `Delete` | 删除选中流量 |
| `Ctrl/⌘ + A` | 全选 |
| `↑` `↓` | 切换选中项 |
