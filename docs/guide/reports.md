# 报告

FlowMind 内置完整的报告系统，支持将测试结果导出为结构化报告，便于记录、分享和归档。

![报告-概览](/screenshots/报告-概览.png)

## 报告页面

报告页面分为 5 个标签页：

| 标签 | 功能 |
|------|------|
| **概览** | 数据仪表盘，展示发现统计、素材数量、备忘录数量、已导出报告 |
| **发现** | 完整的 Finding 浏览器，支持过滤、批量操作、单条状态管理 |
| **素材** | 素材剪藏管理，支持自由笔记和引用流量/发现 |
| **备忘录** | 富文本备忘录编辑器 |
| **生成** | 选择格式导出报告，管理已导出的文件 |

## 报告格式

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| **HTML** | 自包含的目录包（`index.html` + `assets/`） | **推荐** — 可在浏览器直接打开，包含完整交互式导航和样式 |
| PDF | 可打印文档格式 | 正式交付、打印归档 |
| JSON | 结构化数据格式 | 程序化处理、二次分析 |

## 导出报告

### 导出步骤

1. 进入 **报告** → **生成** 标签页
2. 选择导出格式（推荐 HTML）
3. 选择保存位置：
   - **默认报告目录**：保存到工作区 `reports/{project-id}/`
   - **选择其他目录**：通过系统对话框选择任意目录
4. 等待导出完成，自动打开报告所在目录

### 报告数据

导出报告包含以下章节：

| 章节 | 内容 |
|------|------|
| **封面** | 项目名称、描述、目标 URL、生成时间、工具版本 |
| **执行摘要** | 总览统计数据（请求数、域名数、发现数、严重程度分布、处理状态分布） |
| **评估说明** | 目标 URL、测试范围、测试账号、测试周期、评估人员 |
| **流量画像** | 协议组成、方法分布、状态码分布、Top 10 域名、Top 10 路径 |
| **发现问题** | 按来源（扫描/AI/手动）和严重程度分组的发现列表 |
| **涉及域名** | 所有涉及的域名列表 |
| **附件** | 工具版本、插件列表、项目笔记、素材剪藏、备忘录、项目笔记附件 |

## Finding 管理

### 发现浏览器

在 **报告** → **发现** 标签页中：

- **搜索**：按关键词搜索发现
- **严重程度过滤**：High / Medium / Low / Info
- **状态过滤**：Open / Confirmed / Fixed / Ignored
- **批量操作**：批量删除、全部删除
- **展开详情**：查看问题描述、修复建议、影响 URL 列表

### 单条管理

每条发现的每个出现位置（Occurrence）都可单独管理：

- **状态标记**：确认、已修复、忽略
- **备注**：添加自定义备注
- **添加素材**：将该发现添加到报告素材
- **查看关联 Flow**：直接跳转到关联请求

### 发现来源

系统自动标记每条发现的来源：

| 来源 | 说明 |
|------|------|
| 扫描 | 内置规则或插件触发的自动检测 |
| AI | AI 安全分析生成的发现 |
| 手动 | 用户手动创建的发现 |

## 素材剪藏

### 素材类型

| 类型 | 说明 |
|------|------|
| 流量 | 从转发器捕获的请求 |
| 发现 | 安全发现记录 |
| 笔记 | 用户自定义的自由笔记 |

### 添加素材

1. **从转发器**：右键请求 → **添加到素材**
2. **从发现**：在发现详情中点击 **添加素材**
3. **手动添加**：在 **素材** 标签页填写标题和内容

### 管理素材

在 **报告** → **素材** 标签页中：

- 查看所有素材（卡片式展示）
- 上移/下移调整顺序
- 编辑标题和内容
- 删除素材

## 备忘录

### 使用备忘录

在 **报告** → **备忘录** 标签页中：

1. 左侧边栏列出所有备忘录
2. 点击备忘录查看或编辑
3. 新建备忘录：填写标题和富文本内容
4. 删除不需要的备忘录

### 用途

- 记录测试思路和发现
- 待验证的猜想
- 测试计划
- 与报告相关的备注

## HTML 报告详情

HTML 报告是一个自包含的目录包，结构如下：

```
report-{project-name}-{timestamp}/
├── index.html          # 主页面
└── assets/
    ├── report.css      # 样式文件
    ├── report.js       # 交互脚本
    └── notes/          # 项目笔记附件
```

### HTML 报告特性

- **侧边栏导航**：快速跳转到各章节
- **滚动监听**：自动高亮当前阅读位置
- **筛选功能**：按严重程度和状态筛选发现
- **打印优化**：支持打印为 PDF
- **响应式设计**：桌面和移动端均可阅读
- **包含附件**：项目笔记附件自动嵌入

## 使用建议

### 报告内容

1. **包含关键发现**：确保重要 Finding 在报告中
2. **添加上下文**：使用素材和备注补充说明
3. **项目笔记**：在项目中撰写测试说明和结论

### 格式选择

1. **正式交付**：使用 HTML（推荐）或 PDF 格式
2. **技术交流**：使用 JSON 格式
3. **内部记录**：HTML 格式最为直观

### 工作流建议

1. 测试过程中随时通过右键菜单添加素材
2. 在备忘录中记录测试想法
3. 测试完成后再生成最终报告
4. 使用默认报告目录便于管理
